    Availability snapshot: Oct 21, 2026 · 8:22 AM ET. Open "Injuries & availability" on each game for player reports. This is a saved snapshot, not live data; no injury adjustments have been applied to either model.

    Alpha · football_adjusted_no_margin_10 — frozen ridge-10 fit, 2022–2024. Exact reproduction of the live model; coefficients loaded from the saved fitted_model.json, not re-estimated.

    Beta · Alpha + signed tier_gap (strict P4/G5) — joint refit, ridge-10, same 2022–2024 window. tier_gap = +1 home P4/away G5, −1 home G5/away P4, 0 otherwise.

    Both models predict home scoring margin from football data alone, with no market inputs. The market spread enters only afterward, to measure the difference. Opponent-adjusted ratings refit on all completed 2026 FBS-vs-FBS games through Week 7. Only 0 of this week’s games carry a nonzero tier_gap (flagged on the card) — everywhere else Alpha and Beta differ only by ordinary refit noise.

    Track record. Alpha went 364–370–18 ATS (49.6%) in the 2025 retrospective test. Average margin error: 12.97 points versus 11.89 for the market. Live 2026 results are on the Model performance page.

    Alpha inputs: net PPA, success rate, explosiveness, points per opportunity, havoc, turnover margin, neutral site, rest difference, and two opponent-rating features (offense and defense differences), blended with a four-game prior weight against 2025 team profiles. Beta is a full joint refit of Alpha’s 10 features plus one signed tier_gap feature — not Alpha plus a fixed correction, so even tier_gap=0 games can show small differences.

    “Where the margin comes from” is the same linear math the model already uses — each feature’s standardized value times its fitted coefficient — broken apart per feature. Neither model sees market lines, totals, or moneylines. 2025 has been examined repeatedly, so it is not a pristine holdout.
